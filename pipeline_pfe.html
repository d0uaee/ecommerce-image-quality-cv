Plan d'exécution (version PFE)

Phase A - Data & Prétraitement

Collecte multi-sources (fonds variés, catégories variées), nettoyage, normalisation, split train/val/test.

Phase B - Détection intelligente

OCR du produit, extraction mots-clés, génération de prompt, détection robuste avec fallback.

Phase C - Scoring hybride

CV classique + CNN qualité globale, puis fusion et explication interprétable pour l'utilisateur.

Phase D - Recommandation & business insights

Produits similaires (image + texte), estimation prix, signaux de popularité, recommandations e-commerce.

Stack technique visée

Streamlit OpenCV OCR (EasyOCR / Tesseract) Grounding DINO GrabCut PyTorch CNN custom CLIP embeddings FAISS / Nearest Neighbors API externes (prix/popularité)
Message clé pour la soutenance: la version actuelle valide la faisabilité technique, et la roadmap transforme le prototype en système intelligent complet (CV + NLP + recommandation) avec impact concret pour e-commerce.

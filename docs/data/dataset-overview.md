# Vue d'ensemble du dataset

## Scope

Le dataset final est limite a trois categories :

- `shoes`
- `clothing`
- `portable_electronics`

## Organisation

- `dataset/originals/` : images propres
- `dataset/degraded/` : images degradees
- `dataset/metadata.csv`
- `dataset/degraded_metadata.csv`

## Volume final

- `180` images propres
- `3240` images degradees

## Philosophie

Les mauvaises images ne sont pas collectées directement. Elles sont generees par degradation controlee a partir d'images propres.

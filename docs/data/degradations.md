# Degradations controlees

Les degradations appliquees sont :

- `blur`
- `lowres`
- `bad_crop`
- `underexposure`
- `overexposure`
- `jpeg`

## Niveaux

Chaque degradation existe en :

- `low`
- `medium`
- `high`

## Objectif

Chaque famille de degradation sert a tester la sensibilite du systeme sur un type de defaut visuel bien defini.

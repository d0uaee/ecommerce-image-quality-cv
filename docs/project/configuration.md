# Configuration

La configuration centrale se trouve dans `config.py`.

## Sections importantes

- chemins dataset
- poids du score global
- seuils des criteres
- configuration DINO
- configuration Streamlit
- configuration Assistant annonce / n8n

## Parametres notables

- categories supportees :
  - `shoes`
  - `clothing`
  - `portable_electronics`
- poids calibrés du score final
- activation optionnelle du webhook n8n

# Structure du depot

## Fichiers racine

- `app.py`
- `config.py`
- `README.md`
- `DOCUMENTATION.md`
- `LIVRABLE_PROF.md`

## Dossiers principaux

- `src/` : coeur du pipeline
- `dataset/` : donnees finales et metadonnees
- `output/reports/` : rapports d'evaluation
- `deliverables/` : support de soutenance
- `scripts/` : scripts utilitaires et experimentaux

## Philosophie d'organisation

Le depot distingue clairement :

- l'execution de l'application
- la logique de traitement
- les donnees
- les rapports experimentaux
- les livrables académiques

# Quickstart

## Workflow minimal

1. Installer les dependances
2. Lancer `streamlit run app.py`
3. Ouvrir l'application
4. Charger une image
5. Fournir un titre et une description
6. Lire le score global et les sous-scores

## Premier test recommande

Utiliser une image du dossier :

- `dataset/originals/shoes/`
- `dataset/originals/clothing/`
- `dataset/originals/portable_electronics/`

Puis verifier :

- le crop selectionne
- le score global
- la coherence image / texte
- les recommandations generees

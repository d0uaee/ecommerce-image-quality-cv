# Premiere execution

## Ce que vous devez verifier

Lors de la premiere execution, verifier les points suivants :

- l'application Streamlit s'ouvre correctement
- une image peut etre chargee
- le texte vendeur est bien pris en compte
- un score global apparait
- les criteres individuels sont visibles

## Modes principaux

- **Analyse unique**
- **Assistant annonce**
- **Batch**

## Fichiers utiles des le premier run

- `dataset/metadata.csv`
- `output/reports/evaluation_report.md`
- `output/reports/multi_annotator_report.md`

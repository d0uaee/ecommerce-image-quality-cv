# Vue d'ensemble

## Qu'est-ce que ce projet ?

**E-commerce Image Quality** est un projet PFE qui propose un pipeline zero-shot pour evaluer automatiquement la qualite de photos produit e-commerce. Il ne repose sur aucun entrainement de modele local dans ce depot.

## A quoi sert-il ?

Le systeme a ete pense pour aider de petits vendeurs, des operateurs e-commerce ou des equipes techniques a verifier rapidement si une photo produit est publiable.

## Principales fonctionnalites

- evaluation qualite photo
- score global explicable
- sous-scores interpretables
- coherence image / texte
- recommandations en francais et en darija
- mode batch
- mode debug
- extension **Assistant annonce**

## Positionnement

Le projet ne cherche pas a concurrencer un systeme supervise industriel. Sa valeur principale est :

- une architecture zero-shot multimodale
- une logique explicable
- un protocole experimental propre
- une validation humaine defendable

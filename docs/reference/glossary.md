# Glossaire

- **Zero-shot** : approche sans entrainement specifique sur la tache locale
- **CLIP** : modele multimodal texte / image pre-entraine
- **Crop** : region d'image retenue
- **Framing** : qualite du cadrage produit
- **Spearman** : mesure de correlation par rangs
- **p-value** : indicateur de significativite statistique

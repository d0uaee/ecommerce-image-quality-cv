# Calibration et analyses complementaires

Scripts importants :

- `scripts/calibrate_weights.py`
- `scripts/analyze_disagreements.py`
- `scripts/evaluate_by_category.py`
- `scripts/evaluate_multi_annotator.py`
- `scripts/test_dino_fallback.py`

## Objectif

Ces scripts servent a :

- mieux aligner le score avec le jugement humain
- comprendre les cas d'erreur
- comparer les categories
- mesurer l'accord inter-annotateurs

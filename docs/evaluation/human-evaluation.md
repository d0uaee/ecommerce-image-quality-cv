# Validation humaine

## Principe

Un echantillon d'images a ete annote manuellement pour comparer le score automatique au jugement humain.

## Resultat principal

- `Spearman rho = 0.7122`
- `p-value = 6.64e-09`

## Interpretation

Le systeme suit bien le jugement humain tout en restant zero-shot.

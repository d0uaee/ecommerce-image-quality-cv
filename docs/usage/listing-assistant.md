# Assistant annonce

## Role

L'assistant annonce est une extension produit qui aide a generer :

- un titre
- une description
- des attributs
- une checklist vendeur
- un prix indicatif prudent

## Deux modes

- `n8n_webhook` si un webhook externe est configure
- `local_assistant` sinon

## Point important

Cette extension ne remplace pas le pipeline scientifique principal d'evaluation qualite.

# Choix methodologiques

## Hypotheses structurantes

- texte de l'annonce = source de verite principale
- aucun OCR dans le chemin critique
- aucun entrainement de modele local
- scope reduit a trois categories

## Justification

Ces choix rendent le projet plus simple a expliquer, plus rapide a construire et plus defendable dans un cadre PFE.

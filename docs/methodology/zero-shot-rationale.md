# Pourquoi une approche zero-shot ?

## Choix central

Le projet adopte une approche zero-shot pour rester :

- rapide a prototyper
- explicable
- realiste dans un cadre PFE
- peu dependante d'un gros dataset annote d'entrainement

## Ce que cela implique

- aucun entrainement de modele local
- reutilisation de modeles pre-entraines
- calibration du score final plutot qu'apprentissage supervise

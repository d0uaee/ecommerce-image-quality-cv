# Traitement du texte

Le texte est traite dans `src/text_processor.py`.

## Role

- nettoyer le texte
- extraire des indices (categorie, marque, couleur)
- produire un embedding texte

## Hypothese cle

Le texte vendeur constitue la source de verite principale.

## Limites

- si le texte est faux ou trompeur, la coherence image / texte peut etre degradee
